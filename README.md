# 🕵️ Anonymous Agent

A private, fast, and lightweight search interface built with vanilla HTML, CSS, and JavaScript.

> **No installation required. No Tor needed. Just open and search.**

---

## 🌐 Live Demo

👉 **[https://tahmidandanas-creator.github.io/Anonymous-Agent/](https://tahmidandanas-creator.github.io/Anonymous-Agent/)**

Works in **any modern browser** — Chrome, Safari, Firefox, Edge, Brave, Opera.

---

## ✨ Features

- 🔍 **Instant search** via DuckDuckGo (clearnet)
- ⚡ **Real-time suggestions** as you type
- 🎨 **Modern glassmorphism dark UI**
- 📱 **Fully responsive** — mobile, tablet, desktop
- ⌨️ **Keyboard navigation** (↑ ↓ Enter Esc)
- 🚫 **Zero tracking, zero logs, zero analytics**
- 🪶 **No frameworks, no dependencies, no build step**
- 💯 **100% static** — hosted for free on GitHub Pages

---

## 📋 Requirements

To use the app, you need **only one thing**:

| Requirement | Details |
|-------------|---------|
| ✅ **A modern web browser** | Chrome 60+, Safari 12+, Firefox 55+, Edge 79+ |
| ✅ **An internet connection** | To load suggestions and search results |

That's it. **No Tor, no VPN, no extensions, no accounts, no sign-ups.**

---

## 🚀 How to Use

1. Open the live site:  
   👉 https://tahmidandanas-creator.github.io/Anonymous-Agent/
2. Type anything in the search bar (e.g., "privacy tools")
3. Either:
   - Tap a **suggestion** from the dropdown, or
   - Press **Enter**, or
   - Tap the **SEARCH** button
4. You'll be redirected to **DuckDuckGo** search results.

---

## 🔒 Privacy

- ❌ No cookies are set by this app
- ❌ No analytics or tracking scripts
- ❌ No data is stored or sent anywhere except DuckDuckGo (when you search)
- ✅ Search queries go directly from your browser to DuckDuckGo
- ✅ The app itself is fully static — nothing runs on a server

> **Note:** DuckDuckGo's own privacy policy applies to searches performed through their service. Learn more at [duckduckgo.com/privacy](https://duckduckgo.com/privacy).
